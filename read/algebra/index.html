Algebra

Algebra Cheat Sheet

Properties, radicals, rational expressions and the quadratic formula — the working rules and the common shapes.

Algebra is arithmetic with unknowns. Variables stand for numbers; properties and rules let you rewrite expressions without changing their value.

The properties of arithmetic

  • Commutativea + b = b + a, a · b = b · a — order does not matter
  • Associative(a + b) + c = a + (b + c), (a · b) · c = a · (b · c)
  • Distributivea · (b + c) = a · b + a · c — the single most used rule
  • Identitya + 0 = a, a · 1 = a
  • Inversea + (−a) = 0, a · (1/a) = 1

The distributive pattern in full

a(b + c) = ab + ac (a + b)(c + d) = ac + ad + bc + bd FOIL is just the distributive law applied twice.

Radicals (the geometric-mean family)

  • √x · √y√(x·y) — the square root distributes over products, not sums
  • √x ÷ √y√(x ÷ y) — same for quotients
  • √x + √xyou cannot combine different radicands
  • (√x)²x — for x ≥ 0 the square and the root cancel
  • √(a²)|a| — not a itself: sign survives the square root

The quadratic formula

x = (−b ± √(b² − 4ac)) ÷ 2a Solves any ax² + bx + c = 0 with no factoring required.
  • b² − 4ac > 0two real roots
  • b² − 4ac = 0one repeated root — the curve touches the axis
  • b² − 4ac < 0no real roots — the curve never reaches the axis

Rational expressions

A fraction of polynomials is a rational expression. Cancel common factors only when they are factors of the whole numerator and the whole denominator — never cancel just an a out of each term.

a·x ÷ a·y = x ÷ y x ÷ (a·y) = x ÷ a ÷ y — powers of a multiply and divide freely
Note The classic algebra mistakes: cancelling terms that are not factors, √(a²) = a when a < 0, and dividing by a variable before checking it could be zero.
