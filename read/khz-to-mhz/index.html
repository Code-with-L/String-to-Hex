Frequency conversion

Kilohertz to Megahertz

Convert kHz to MHz.

1 MHz = 1000 kHz.

Conversion formula

MHz = kHz / 1000

Examples

1000 kHz = 1 MHz
500 kHz = 0.5 MHz
2400 kHz = 2.4 MHz
Note Divide kilohertz by 1000 to get megahertz.
