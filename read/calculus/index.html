Calculus

Calculus Cheat Sheet

Derivatives, limits and integrals — the rules you actually use most often, with worked examples.

Calculus is the mathematics of change: derivatives measure how fast something changes, integrals measure how much accumulates.

Definitions worth memorising

  • Derivativef′(x) = lim(h→0) (f(x+h) − f(x)) ÷ h — the slope of the tangent
  • Integral∫ f(x) dx — the area under the curve, the inverse of the derivative
  • Limitlim(x→a) f(x) — the value f(x) approaches, never necessarily reaches

The fundamental theorem

F′(x) = f(x) ∫ₐᵃ f(t) dt = 0 ∫ₐᵇ f(t) dt = F(b) − F(a)

Derivative rules (with examples)

  • Power ruled/dx xⁿ = n·xⁿ⁻¹ — multiply by the exponent, drop it by one
  • Constant ruled/dx c = 0 — nothing about a constant changes
  • Constant multipled/dx (c·f) = c·f′ — constants sail through
  • Sum ruled/dx (f + g) = f′ + g′ — differentiate term by term
  • Product ruled/dx (fg) = f′g + fg′ — never f·g with a single plus
  • Quotient ruled/dx (f/g) = (f′g − fg′) ÷ g²
  • Chain ruled/dx f(g(x)) = f′(g(x)) · g′(x) — outside × inside

Integration rules

  • Power rule∫ xⁿ dx = xⁿ⁺¹ ÷ (n + 1) + C, n ≠ −1
  • 1 ÷ x∫ (1/x) dx = ln|x| + C
  • eˣ∫ eˣ dx = eˣ + C
  • sin x∫ sin x dx = −cos x + C
  • cos x∫ cos x dx = sin x + C
  • Substitution∫ f(g(x))·g′(x) dx = ∫ f(u) du, u = g(x)
  • Parts∫ u dv = uv − ∫ v du

Limit rules

  • Constantlim(x→a) c = c
  • Sumlim (f + g) = lim f + lim g
  • Productlim (f · g) = lim f · lim g
  • Quotientlim (f ÷ g) = lim f ÷ lim g, provided lim g ≠ 0
  • Sandwichif g ≤ f ≤ h and lim g = lim h, then lim f = both
Note The derivative of a product is not the product of the derivatives, and d/dx f(g(x)) is not f′(g(x)) — the chain rule is the difference between a right answer and a mess.
