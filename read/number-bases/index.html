Number Bases and Radix

Why positional notation works, and why binary, octal and hexadecimal are the natural companions of each other.

A positional numeral system represents a number as a sum of digits multiplied by powers of the base. The base is the number of distinct digits available, counting from zero.

value = Σ dᵢ · bⁱ dᵢ is the digit at position i, b the base. The rightmost digit is position 0.

Why hexadecimal exists

Base 16 is exactly 2⁴. That is the whole reason hex is used to display binary: one hex digit is precisely four bits, so a byte is always two hex digits with nothing left over.

1 hex digit = 4 bits = ½ byte Binary: 01001000 01101001 Hex: 48 69

Octal, 8 = 2³, is the same idea for three-bit groups and was common on 12- and 18-bit machines.

Converting by hand

From any base to base 10, multiply-accumulate left to right. From base 10 to any other base, divide repeatedly and read the remainders upwards.

255₁₀ → 11111111₂ → FF₁₆ → 377₈

Why exact integers matter

JavaScript numbers are 64-bit floating point, which holds integers exactly only to 2⁵³. Above that, ordinary arithmetic silently rounds. A base calculator built on BigInt has no such limit, which is why this one uses BigInt throughout.

Note In this app every base operation runs on BigInt, so 2⁵³, 2⁶⁴ and beyond are computed exactly rather than approximately.
