Fundamentals

Electrical Current

Charge in motion, how much of it flows, and what limits it.

Electric current is the rate of flow of electric charge past a point in a circuit.

I = Q / t One ampere is one coulomb per second.
  • Icurrent, in amperes (A)
  • Qcharge, in coulombs (C)
  • ttime, in seconds (s)

Conventional current is defined in the direction positive charge would move. In metals the actual carriers are electrons moving the other way — the numbers are identical, only the sign convention differs.

Conventional vs electron flow

  • Conventional current runs from the positive terminal of a source to the negative.
  • Electron flow runs the opposite way in metallic conductors.
  • Either convention gives correct results as long as you use one consistently.

Current in series and parallel

In series there is only one path, so the same current flows through every component.

I_T = I₁ = I₂ = I₃

In parallel the voltage across each branch is the same and the branch currents add up to the total.

I_T = I₁ + I₂ + I₃

Measuring current

An ammeter is connected in series — it must carry the same current as the branch it measures. Its resistance is very low so that it does not change the circuit.

Note Connecting an ammeter directly across a source is close to a short circuit. Almost all the supply voltage appears across near-zero resistance, which is why the current — and the damage — is very large.
