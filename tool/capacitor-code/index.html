What it calculates

Read the three- or four-digit EIA code printed on ceramic capacitors — like the resistor colour code for capacitors. Results appear instantly as you type, and the “show the working” panel lists every step so the answer can be checked by hand.

How to use it

  1. Open the calculator and fill in the input fields.
  2. The result updates as you type; the working is shown beneath the results.
  3. Copy the result, or share the URL — your inputs are stored in it.
